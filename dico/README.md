# Bundled TELEMAC-MASCARET dictionaries

These are the official `.dico` files of the open-source TELEMAC-MASCARET system,
copied unmodified from the release tags of the official repository
(<https://gitlab.pam-retd.fr/otm/telemac-mascaret>):

| Folder | Release tag | Modules |
| --- | --- | --- |
| `9.1.2/` | `v9.1.2` | 10 (Sisyphe was removed in v9; use Gaia) |
| `8p4/` | `v8p4r1` | 11 |

Copyright (c) TELEMAC-MASCARET Consortium. Distributed under the GNU General
Public License v3; see `COPYING` in this folder.

To refresh them from a TELEMAC-MASCARET git clone, run
`scripts/export_dico.sh <tag> <output folder>`.
